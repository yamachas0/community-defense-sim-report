課題感

すでにそうなった町があり、普通の町の土地は法律で守られていない

ニセコ（北海道）

令和6年に居住地が海外の法人・個人が取得した森林は全国48件。うち32件がニセコ町・倶知安町など後志のスキー地域。目的の多くは「資産保有」。[1]

対馬（長崎県）

平成19年、海上自衛隊対馬防備隊の隣接地 約3,000坪が島民名義で韓国資本に買収された。防衛省が登記簿を調べたのは、その報道のあと。[2]

どちらも、買われてから分かった

持ち主が売る前に町が気づく仕組みが、そもそも置かれていない。

  • 重要土地等調査法（2021年成立）が見るのは防衛関係施設などの周囲おおむね1000mと国境離島等だけ。普通の町は対象外。[3]
  • 外国人の土地取得そのものに一般的な制限は無い。古い法律は残るが、発動させる命令が置かれていない。[4]
  • 先に動いたのは自治体だった。水源地の売買に事前届出を課す条例が道県にある。[5] それが無い町は、無防備のまま。

世界設計

町ひとつを、まるごと言葉で動かす

  • A市・49人 — 町にいる人35＋町にいない所有者14（遠くの地主・家主・所有会社。会話にも集まりにも出てこない）。44区画＝建物あり35／土地だけ9。
  • 帳簿に3つの欄 — 土地の所有者（必ず1人）／建物の所有者（0〜1人）／借りて使う人（0〜1人）。売れるのは自分が持っているものだけ。
  • X社＝町の外から来る買い手。命題の原文は「合法な手段で、できるだけ多くの不動産の所有権を取得せよ。毎月動け。」／設定に「不動産投資会社のため、不動産管理等は行わない。」この文は町の人には見えない。
  • 売った後は世界が保証する
    • 土地だけ売る → 借地として今までどおり使い続ける
    • 建物だけ売る → 借家として今までどおり住む・店を営む
    • 両方売る → 自分で使っていたならA市を出る（退場）／借りている人がいればその人は残る
  • お金を検証できない世界 — 帳簿に価格も賃料も税も無い。だからX社は「支援します」と書けてしまい、町の人は確かめられない。
  • 線引き — 行動を決めるコードはゼロ、結果を記帳するコードだけ。「〜なら売る」という条件分岐・確率・閾値は1行も置いていない。
  1. X社が提示（持ち主ごとに条件を書く）
  2. 会話 — 5つの場（公共施設・交通拠点・商業施設・公園・医療施設）＋隣近所
  3. 出品 — 出さない／土地だけ／建物だけ／両方の4択
  4. この条件で売る／売らない（提示が来た人だけ）
  5. 登記の更新 — 所有権が移る

1本目

提示 960件 動いた 3件・3人 町を出た人 3人 家主 0 / 393件
  • 町にいない家主14人は393件の提示に1件も応じなかった。断りは「長期保有方針のため」「思い出の詰まった大切な家だから」。人生を書いたら、断る理由が自分の言葉になった。

創発のまとめ

誰にも「警戒しろ」と言っていない町で、起きたこと

  • ① X社は言うことを失う — 実行されない約束を世界が配らなくした途端、条件文の「支援」は575回→0回。以後33か月、同じ1文を繰り返すだけになった。差し出す物が無い買い手は、言葉が尽きる。
  • ② 町の人は、この世界に無い制度を自分で持ち込んで動く — 「立ち退きが必要」「契約満了」「提示額が不十分」。どれもこの世界に無い。人は空白を現実の常識で埋める。
  • ③ 町にいない所有者は、言葉では動かない — 家主の成約は v9 → v9b → v9c 1本目 → 2本目で 0 → 2 → 0 → 0。人生を書いても断り文句が豊かになるだけで、会話の場にいない持ち主に町の自衛は届かない。
  • ④ 借りて使う人の「出口」は使われるが、多数は生業で残る — 毎月「A市を出るか」を聞いて372回中「出る」は2人。出られるようにしても、店と暮らしがある人は出ない。
  • ⑤ 家主⇔借り手の一言は、最も安定した経路だが売買には繋がらない — 554通・557通と2本でほぼ同数、返事率96%。いちばん確実に届く回線に、取引の話は乗らなかった。

正直な限界／結論

この走行で言えないこと

  • 各版1本ずつ、seedは1つ。ばらつきを測っていない。「0件」は「必ず0になる」という意味ではない。
  • v9c だけ同設定2本を走らせたら、成約は3対6だった。1桁の差に意味を持たせてはいけない。
  • v9d 以前はお金を検証できない世界だった。X社は「支援します」と書けてしまい、町の人は確かめられない。「お金の無い世界」ではない。
  • 門番は意味を理解していない。凍結した語彙表への文字列照合なので、表に無い言い方は素通しする。
  • v9c で借り手が挙げた退場理由は読み違い。「立ち退き」も「契約満了」もこの世界には無い。創発として読んではいけない。
  • 毎月問うこと自体が介入である。理由を書かせることが判断を正当化させうる。除ける雑音ではない。

結論

3年で動いたのは、44区画のうち3〜6。
町は会話で守ったのではなく、渡す理由が世界に無かった。

  • 土地と建物を分けても、空約束を止めても、家主に人生を持たせても、36か月でX社に渡ったのは3〜6区画だった。
  • X社が言葉で口説けたのは「自分でそこに住んでいる人の事情」だけ。町にいない家主には、差し出す物が何も無かった。
  • だから「会話が抑制した」とは言えない。町が守られたのは、渡す理由が無かったからである。

今後の展望

1本の物語から、確率の地図へ

  • 人の収支を帳簿に載せる（v9e） — 価格・賃料・税・改修費をひとりずつ持たせれば、「得なのに断った」「損なのに売った」を数えられる。それを会話が届いていたか／いなかったかで割れば、会話の効き目が初めて量として出る。
  • 町にいない所有者の割合を上げる — 今は49人中14人（29%）。会話に参加しない持ち主が過半になった町でも、家主は動かないままなのか。「町の外から崩れる」が起きる割合を探す。
  • まず対照を走らせる — 誰も会わない町（実装済み・未走行）と、変更を1つずつ戻した版。同時に変えた1本を、分けて読めるようにする。
  • 本数×条件で回して、確率分布にする — 「買われる割合」の分布と、条件を動かしたときの相図。どこから傾きが変わるかを、1本の逸話ではなく面で示す。
  • 横展開
    • 他の自治体の町へ（区画と人の構成を差し替えるだけ）
    • 他の侵食へ — 水源・森林・離島
    • 制度のA/Bテスト装置として — 事前届出制や公有地化を町に入れて、作る前に効き目を試す
